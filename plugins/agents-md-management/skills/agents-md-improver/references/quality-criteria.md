# AGENTS.md quality criteria

Score each existing file for its intended scope. Read applicable parent instructions before penalizing a nested file for omitting inherited material.

| Criterion | Points | Evidence |
| --- | --- | --- |
| Commands and workflows | 20 | Commands are current, their working directories are clear, and the expected test or build scope is stated |
| Architecture clarity | 20 | Key boundaries and entry points orient work in this scope |
| Non-obvious patterns | 15 | Rules capture real invariants, pitfalls, or package relationships |
| Conciseness | 15 | Content is easy to scan, avoids duplication, and fits the scope |
| Currency | 15 | Paths and procedures agree with code, CI, or verified behavior |
| Actionability | 15 | Instructions are concrete enough to follow or verify |

Grade bands are A 90–100, B 70–89, C 50–69, D 30–49, and F 0–29. Explain substantial deductions with evidence. Distinguish stale advice, missing guidance, conflicting instructions, and shadowed files. Score existing files only, and report absences separately.
